# Match AI players

Started: 2026-10-22. Branch `feature/AI_players`.

## Scope

- AI subcomponent of the MATCH code in game_common (not world code), server side only, emits input commands.
- Same behavior for all AIs. Decision code may be non-deterministic, never mutates the world.
- Layered decisions (strategy -> tactics), per-AI state machine and per-player opinion values.

## Shape

- `include/game_common/match/ai/match_ai.h` (`ai_player_state`, `AI_MODE`, `ai_update`); code in `src/game_common/match_ai/`: `_main` (cadence), `_world` (only file reading the world), `_opinion`, `_strategy`, `_tactics_economy|expansion|military`, `_internal.h` (tuning constants). Imprints: `match_ai.imprint.md`, `game_mechanics.imprint.md` (user to review); `.ai_imprint/` has scratch test program + state machine notes.
- Server calls `ai_update` for every AI each tick before `match_tick`; AI decides when `tick % 20 == player % 20`, with sub-cadences by `decision_index` (campaign every, threat 2nd, tactics 3rd on a window of 6 settlements, strategy 5th).

## Decisions

- AI reads world directly (parallel-to-sim revisited later).
- Decisions staggered per tick, not per day (reactive, hundreds of AIs).
- No peace period: AI attacks allowed from day one.
- Keep max-taxes behavior. AI code stays in wasm client build (single-player later).
- Next-tick command arena = 256 bytes per player (`COMMAND_BYTES_PER_PLAYER`); AI skips silently when full.
