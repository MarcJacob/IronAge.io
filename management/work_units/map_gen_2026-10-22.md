# Procedural map generation

Started: 2026-10-22. Branch `feature/map_gen`. Related backlog: `map_from_image_2026-10-13.md` (hand-authored bitmap maps, later).

## Scope

- Boolean on match parameters: procedural map or not.
- Struct of generation parameters inside match parameters (transmitted to the client with the rest).
- Deterministic procedural generator: plains, hills, mountains, lakes / seas with coasts. No biomes.
- Self-contained subsystem of game_common, outside world sim, friendly to later bitmap loading.

## Shape

- `src/game_common/map_gen/` (`map_gen.h`, `_main`, `_heightmap`, `_apply`): `map_gen_heightmap` (size + 1 elevation byte per tile) -> `map_gen_apply_heightmap`. Bitmap loader = fill a heightmap and call apply.
- `map_gen_generate` called from `world_state_init` when `procedural_map`; tile status init split out as `world_terrain_init_tile_status`.
- Params: `include/game_common/match/map_gen_params.h` (`sea_level_bias`, `hills_bias`, `mountains_bias`, `feature_scale_tiles`; zero = default) inside `start_params.h`; mirrored in `backend.ts` (start params 18 -> 24 bytes).
- Noise / fixed-point helpers: `include/core/math/noise.h`, `numerical.h`.
- Test scenario (`game_common_tests.cpp`) sets `procedural_map = true`.
- Unplug: remove include + branch in `world_state_init`, delete folder, drop fields in `start_params.h` and `backend.ts`.

## Decisions

- Constants tuned by eye (sea 105, hills +40, mountains +85, 48-tile border sea); mountains are blobs more than ranges.
